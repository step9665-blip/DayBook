# 📝 Мои ежедневники - Daily Planner App

Полнофункциональное веб-приложение планера с поддержкой создания нескольких ежедневников, управлением задачами и тремя видами (День, Неделя, Месяц).

## 🚀 Развертывание на Netlify

### Способ 1: Через GitHub (Рекомендуемый)

1. **Создайте GitHub репозиторий:**
   - Перейдите на https://github.com/new
   - Назовите его `planner-app`
   - Создайте репозиторий

2. **Загрузите файлы проекта:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/planner-app.git
   cd planner-app
   
   # Скопируйте все файлы проекта в эту папку
   # (файлы: package.json, public/, src/)
   
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```

3. **Подключитесь к Netlify:**
   - Перейдите на https://netlify.com
   - Нажмите "Sign up" и авторизуйтесь через GitHub
   - После авторизации нажмите "New site from Git"
   - Выберите ваш репозиторий `planner-app`
   - Build settings:
     - **Build command:** `npm run build`
     - **Publish directory:** `build`
   - Нажмите "Deploy site"

### Способ 2: Drag & Drop (Быстрый способ)

1. **Соберите проект локально:**
   ```bash
   npm install
   npm run build
   ```

2. **На Netlify:**
   - Перейдите на https://app.netlify.com/drop
   - Перетащите папку `build` на страницу
   - Готово! Ваш сайт будет развернут

## 📋 Локальная установка

1. **Установите Node.js** (если еще не установлен)
   - Скачайте с https://nodejs.org/

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите в режиме разработки:**
   ```bash
   npm start
   ```
   - Приложение откроется на http://localhost:3000

4. **Создайте production build:**
   ```bash
   npm run build
   ```

## ✨ Возможности

- ✅ Создание неограниченного количества ежедневников
- ✅ Цветовые метки для ежедневников
- ✅ Три вида отображения (День, Неделя, Месяц)
- ✅ Категоризация задач (Работа, Личное, Здоровье, Покупки, Прочее)
- ✅ Фильтрация по категориям и поиск
- ✅ Отметить задачу как выполненную
- ✅ Редактирование и удаление задач
- ✅ Сохранение данных в LocalStorage (работает без базы данных)

## 🛠 Используемые технологии

- React 18
- Tailwind CSS
- Lucide React (иконки)
- LocalStorage (для сохранения данных)

## 📌 Важные моменты

- **Данные сохраняются локально** в браузере (LocalStorage), поэтому они не исчезнут даже после перезагрузки страницы
- Для использования на разных устройствах нужна синхронизация через облако (можно добавить позже)
- Приложение работает полностью offline
