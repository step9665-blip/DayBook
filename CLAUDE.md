# DayBook — Заметки проекта

## Рабочий процесс
- **НЕ делать `git push` (деплой) после каждого изменения автоматически.**
  Вносить изменения, собирать (`CI=true npm run build`) и коммитить локально,
  но перед пушем на `main` / `claude/compassionate-franklin-wxp5a8`
  ВСЕГДА спрашивать у пользователя, нужно ли сейчас деплоить.

## Идеи в очереди (не реализованы)

### 1. Авторизация и синхронизация данных
**Проблема:** данные хранятся в localStorage и пропадают при смене устройства/браузера.
**Решение:** Firebase + Google-авторизация
- Кнопка "Войти через Google" (один клик)
- Данные хранятся в облаке, синхронизируются на всех устройствах
- Бесплатный тариф Firebase
- Требует создать проект на firebase.google.com
